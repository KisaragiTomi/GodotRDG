# Third-party materials

- **Godot**: this project targets Godot 4.6.x / Forward+ and was tested with a local
  4.6.1 build at upstream commit `14d19694e0c88a3f9e82d899a0400f27a24c176e`.
  The public repository does not bundle the engine or its source checkout.
  See [Godot downloads](https://godotengine.org/download/archive/4.6.1-stable/)
  and the [Godot MIT license](https://github.com/godotengine/godot/blob/4.6.1-stable/LICENSE.txt).
- **Classic Crytek Sponza**: fetched separately from
  [Khronos glTF Sample Assets](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Sponza).
  Model files, textures, and generated derivatives are not bundled. The upstream
  [model license declaration](assets/sponza/LICENSE.md) identifies the
  Cryengine Limited License Agreement for model-associated files and CC BY 4.0
  for metadata. The downloader preserves those notices; they are separate from
  any license for this project's source code. Demo screenshots show this model.
- **Kenney City Kit Commercial / City Kit Roads**: GLB models and palette textures
  bundled in `assets/kenney_city/`, used to assemble the city demo.
  Both packs are CC0; their original `License.txt` files are preserved in each
  pack directory. See [Commercial](https://kenney.nl/assets/city-kit-commercial)
  and [Roads](https://kenney.nl/assets/city-kit-roads). The download manifest records
  the source archives and SHA-256 hashes; the city layout is generated by this project.
- **Tiny Glade**: an algorithm reference discussed in the research notes.
  This repository contains independently implemented GI and atmosphere experiments, not
  Tiny Glade source, compiled shaders, game binaries, or game assets. It is not
  affiliated with Tiny Glade or its developers.
- Python tools use **NumPy** and **Pillow**, installed separately using
  `tools/requirements.txt`; their respective upstream licenses apply.

Historical audits may reference local source locations that are not part of the
public repository. Generated validation images, buffers, engine binaries and
machine-specific provenance remain local; the README screenshot is a selected
render from this project.
