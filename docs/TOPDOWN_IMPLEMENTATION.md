# TopDown GI 实现记录

本文保留 2026-09-24 的原始俯视场景目标与表面缓存实现记录。当前项目已更名为 Godot Sparse GI，演示支持自由相机；新的实时稀疏追踪路径见 [TG 实现说明](TG_SCREEN_GI.md)。

2026-09-24。目标是固定俯视 3D 场景的稳定间接照明；不把通用自由 3D 视角、自由相机屏幕重建或全场景体素覆盖当作本轮实现要求。

## 当前实现是什么

它是世界空间表面光传输原型，**不是 RC**。`surface_layout.gd` 将每个轴对齐盒的六个面展开到 atlas，保存位置、真实面法线、线性 albedo 和每个面的 atlas 区域。内部埋藏的采样点不发光也不接收光，但对应几何仍遮挡射线。

`cache_transfer.glsl` 对每个有效表面采样点发射确定性的余弦加权半球射线，直接与世界空间轴对齐盒相交，缓存最近命中表面的 atlas UV。射线方向和命中不来自相机；屏幕外的盒与灯仍在输入中。命中定位使用三维几何，因此测试场景可以同时存在地板、台阶、桥面和桥下区域，无需压成单层高度场。

`cache_direct.glsl` 根据点光源位置、颜色、能量、距离衰减、法线和盒遮挡计算初始出射辐射。使用本场景 Godot 非物理光源能量约定，不能直接套到 physical light units / 任意曝光配置。`cache_bounce.glsl` 默认传播两次漫反射：每次只传前一跳，随后乘该表面的 albedo。miss 以黑色参与全部射线的归一化，避免只按命中数归一化而人为提亮开阔表面。

自发光不再依靠半球射线偶然命中高亮小表面。`cache_emitter_transfer.glsl` 对接收半球裁剪后的矩形发光面计算解析投影立体角，再乘 8×8 Gauss–Legendre 采样得到的加权可见率；遮挡使用相同的精确 AABB 线段测试。首次启用自发光时，为所有接收采样点与盒面建立形状因子缓存，因此后续修改发光颜色、能量或启用其他面不重建。第一轮传播单独加上 `emission × factor`，初始出射纹理排除这项；第二轮只传播反射结果，避免重复计入发光。`--legacy-emitter-sampling` 保留旧采样路径供诊断 A/B。

输出 atlas 保存累计间接入射量 `E / PI`。`surface.gdshader` 通过 Godot 的 `IRRADIANCE` 材质输入接入，接收面再使用自身 albedo。`INDIRECT ONLY` 用独立输出显示间接结果。每次光照更新重写有限反弹结果，没有跨帧无限累加，也没有历史降噪。

`--ball` 模式新增一个可移动球形面光源。`cache_sphere.glsl` 对球体可见立体角发射 64 条确定性采样线，用静态 AABB 检查到球面最近交点的遮挡；无遮挡且球体完全位于接收半球时采用解析形状因子 `r²/d² × cos(theta)`，部分遮挡与地平线裁剪使用数值近似。其入射 `E / PI` 单独存入纹理，在第一轮传播加入一次，后续只传播反射结果。没有绑定替代照明的 OmniLight3D。移动、升降、改色及开关只更新两组 vec4 与光照，不重建几何或静态半球命中；静止时无重复 dispatch。最多每秒提交 30 次源更新，球体显示/移动按渲染帧更新。

`EmissiveBall` 使用固定俯视相机的水平基向量解释方向键；Q/Z 升降，小步球-AABB 碰撞允许沿墙滑动并防止穿过薄隔墙。球半径 0.3 米，默认线性辐射倍数 24。动态模式墙面采用 0.25 米间距，9,912 个有效采样点、256 rays；它不重新分配随球移动的细化图块。球体是发光源，不参与静态反射接收或动态遮挡，因此还不是通用动态物体 GI。

## 对俯视场景的取舍

- 采样存在实际表面，而非遍布空体积。地板和向上表面采用 0.25 米默认间距，墙面、底面等采用 0.5 米。优先把预算给俯视画面中占比高的水平接收面。
- 近贴墙发光体需要额外空间分辨率：本例面板背面距墙 0.11 米，原 0.5 米采样会将高梯度照明拉成明显方格，增加每点射线数无济于事。布局对距潜在发光盒不超过 0.5 米、且光源在其正半球的竖直接收面使用最多 0.125 米间距；水平面与远处墙面维持原预算。当前演示仅细化 3 个面，采样数从 5,179 增到 8,037；相比全局 `--wall-spacing=0.125` 的 29,853 点更节省。筛选依据发光颜色而非当前能量，开关灯不影响布局。
- 几何静态时半球射线命中只建立一次。移动光源复用相同传输记录，重新计算直接光和有限反弹；完全不变的照明不 dispatch。
- 发光面缓存为 `采样点数 × 盒面数 × 4` 字节。局部细化后的自发光演示有 8,037 个采样点，额外占用约 3.31 MiB；512-ray 传输记录约 31.39 MiB。几何与遮挡积分只在首次需要时执行，日常改色/调强度只读取缓存。未使用跨帧降噪或画面模糊。
- 光源检查最多每秒 30 次。它是 CPU 提交检查频率上限，不代表 GPU 更新保证在 33 毫秒内完成。
- 镜头只有固定俯视姿态的平移、缩放和投影切换，不扩展自由旋转观察控制。GI 数据本身与相机无关。
- 默认场景有 5,070 个有效表面采样点，关门时为 5,128 个。地基最底面不分配采样，桥底保留。传输缓存占用为 `采样点数 × rays × 8` 字节，默认约 9.90 MiB。提高 rays 增加空间采样质量及更新带宽，不增加跨帧延迟或历史残影。
- 传播命中会在四个邻近表面采样点中寻找最近的可见点，检查命中到采样中心的三维遮挡，存储精确 texel 中心并用 nearest 读取。接收 shader 对 bilinear 四点作面内遮挡和有效性拒绝，只归一化有效权重。无法找到有效样本时返回零，代价是欠采样角落可能偏暗。
- 每个面最多 32 个过滤遮挡矩形；常见无局部遮挡区域使用硬件 bilinear 快速路径，溢出时显式报错并关闭该面缓存贡献。

当前默认并验证的配置是 256 rays、两次反弹。早期 96-ray 试运行已被最终检查覆盖。

## 场景与支持范围

实验场景包括中性色地板、红/蓝反射墙、薄隔墙与门、黑/灰/白接收块、台阶、桥面和桥墩。环境光、glow、雾、SSAO、SSIL 关闭，减少干扰。点光的直接照明由原生渲染器负责，GI 输入使用对应的光源参数。

当前限制：

1. 只支持程序化轴对齐盒。没有任意静态网格三角追踪、旋转盒、斜坡或导入材质支持。不可把显示网格随意旋转/移动后期待缓存自动匹配。
2. 最多 16 个点光源；没有聚光、方向光、天空光或环境贴图贡献。盒体可提供 `emission_color`（sRGB 色）与 `emission_energy`（线性辐射倍数）；`SurfaceLayout.set_emission()` 配合 `SurfaceCache.update_materials()` 更新辐射并复用传播缓存。自发光只支持常量颜色，尚未接入自发光纹理。
3. 几何变化需要显式整体重建。`O` 开关门重新生成布局与传输，是正确性演示，不是完成了动态几何、增量更新或无卡顿流送。
4. 初始光照的阴影和传输建立均逐个遍历盒。没有 BVH / 空间分块加速，场景规模增大时成本随几何数增长。
5. 不支持金属、镜面间接反射、透明透射或复杂 BRDF。面法线真实，但表面采样和 bilinear 重建仍为低分辨率近似；固定 bias 为 0.005 米，也不适合所有尺度。
6. GPU 使用 RGBA16F 纹理。初次默认灯光范围内的有限非负检查通过，不代表极端能量输入不会超出 half-float 范围。
7. 需要 Godot 4.6 Forward+ / RenderingDevice。已在 RTX 5070 的 Vulkan 路径运行；没有测出最低配置，也没有验证 Mobile / Compatibility 或其他 GPU。
8. 发光面无遮挡贡献使用解析值，但部分遮挡的可见率仍是固定 64 点近似，极窄遮挡及半影可能有偏差；后续反射传播仍受半球射线和表面采样分辨率限制。所有面配对的缓存不适合直接扩大到大型场景，需要后续空间裁剪。
9. 近场细化按完整盒面分配，尚未做局部子图或屏幕误差驱动。运行时将原本没有声明发光颜色的普通材质改成光源时，光照仍会正确更新；要获得该新光源附近的密度提升，需要显式重建布局。超近放大仍可暴露有限分辨率，长期可考虑分离逐像素发光直射与低频反弹缓存。
10. 动态球源一次只支持一个、均匀颜色与固定半径；球体自身不遮挡反弹射线。64 点球面可见性在部分遮挡的移动半影处仍可能有采样变化。

## 验证状态

`artifacts/validation/results.json` 保存实际运行参数与检查结果。最终 256-ray Vulkan 运行全部自动检查通过，主要覆盖：

- atlas 有限、非负且含有效光能。
- 镜头平移、缩放和透视切换不触发光照更新，atlas 数据保持一致。
- 将光源实际移出相机视锥后，缓存仍逐字节一致；保存 `offscreen_light.png` 和视锥检查结果。
- 移灯改变 GI，同时保持静态传输建立次数为 1。
- 关灯后 GI 为零，恢复同一灯光参数后 atlas 确定性恢复。
- 关门生成新布局与新传输缓存。

`transport_test.json` 来自单独的 GPU 回归：完全封闭房间中的 4 厘米隔墙刻意放在采样网格之外。左/右单灯测试中，对侧地面最大入射亮度均为零；移除隔墙后右侧获得非零间接光。这同时覆盖射线命中到采样中心的可见性，避免仅仅使用 nearest 仍取到墙另一侧的样本。

同一薄墙测试还覆盖运行后首次启用自发光、切换左右发光墙，以及形状因子仅建立一次。`emissive_quality_test.json` 用 49 个地面采样点对比独立 CPU 128×128 面积分，检查辐射量误差、扣除真实衰减后的空间残差曲率、强度线性、关灯归零和封闭薄墙。无遮挡参考场景的 GPU 平均相对误差约 0.033%，最大约 0.088%；该数值不代表复杂部分遮挡场景精度。演示改动前截图保存在 `artifacts/emissive-before/`，更新结果在 `artifacts/emissive/`。

墙面格子修正的固定近景为 `artifacts/emissive/emissive_detail.png`，原粗密度近景为 `artifacts/emissive-blocky-before/emissive_detail.png`。`--coarse-emitter-receivers` 可关闭该布局策略复现对照。近景只平移和缩放固定俯视相机，不改变 GI 缓存。

`emissive_detail_test.json` 检查实际 GPU atlas 在面板四周 60 个非 texel 中心位置的双线性重建，参考为独立 CPU 512×512 面积分。黑材质隔离了后续反弹，粗布局 RMSE 约 0.16172，细化后约 0.00583（减少约 96.4%），细化后最大绝对误差约 0.00938；并确认只有近接收墙面细化，水平面与远面密度保持不变。这是白色单位辐射、无遮挡近场的受控误差，不是最终图像整体画质百分比。

`material_test.json` 检查实际渲染 shader，给黑/灰/白材质相同的已知入射量 0.25：线性输出约为 0、0.05286、0.25016，符合 sRGB albedo 解码后的 Lambert 响应。人工光照断层下，墙暗侧过滤结果为 0，亮侧为 1，证明接收阶段不跨墙混合。它们仍不是任意拓扑与所有尺度的漏光保证。

`sphere_test.json` 的 GPU 球源结果对比解析衰减，最大相对误差约 0.085%；强度减半、关闭归零和封闭 4 厘米薄墙左右遮挡均通过。`artifacts/ball/results.json` 验证实际输入动作移动球、相机不被方向键移动、升降、墙体碰撞、穿门、颜色传播、可见球体确实发亮、复位确定性和静止零更新；球移动后静态传播建立次数仍为 1。`./tools/validate.ps1 -Emissive -Ball` 可复跑全部相关检查。

GPU timestamp 现在每帧回收，未取得数据时为 null；记录初次建立传输与光照更新的独立区间。最终报告包含 90 帧动态灯光测试、GPU compute 原始样本、viewport GPU 样本及 CPU 帧时间。compute 时间不含材质着色与整个游戏的开销，不能当作总帧预算。

## 计划状态

- **旧实现审计与隔离：已完成。** 原 GI-POE 未修改；修复副本在 `legacy_rc/`。修复同步、探针一致性与拒绝回退，但保留屏幕空间、透视深度和错误材质模型等已注明局限。
- **旧 RC 视觉 A/B：尚未完成。** 副本不挂载在当前主场景，不能声称新结果已经在严格控制条件下击败旧实现。
- **新的 topdown 世界空间 compute：已实现并运行。** 它是本轮的可验证实现选择，没有把表面传输缓存改名为世界空间 RC。
- **VoxelGI 对照：已运行。** 当前验证记录包含成功的原生 VoxelGI 烘焙与截图。没有仅凭原生 API 返回成功宣称质量更优。
- **LightmapGI 固定参考：已完成（2026-10-24 随离线烘焙方案一起删除）。** 原生高质量、两次反弹烘焙；16 个静态网格、一个 atlas。运行模式加载烘焙时使用的确切 UV2 网格，并保留实时直接照明。编辑器恢复场景标签结束后再启动烘焙，避免旧场景被移出树的错误。
- **受控质量与性能验证：已完成。** 截图、材质与薄墙回归、更新行为和 GPU 时间已保留。没有把高端 GPU 的小型场景结果当作产品级帧预算承诺，也没有声称严格画质超过所有原生方案。

后续优先处理实际俯视关卡需要的任意静态网格输入、更高效传输记录与空间加速、受控质量/性能对比，再按真实动态几何需求决定增量更新。通用自由 3D 相机兼容不在目标内。
