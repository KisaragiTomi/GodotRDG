# TG 风格实时 GI 原型

2026-09-28。在 Godot 4.6.1 / Forward+ 中实现了 [Tiny Glade 静态审计](TINY_GLADE_GI_AUDIT.md) 所支持的核心链路：稀疏屏幕射线、软件三角形 BVH 回退、低阶方向光照和时空重建。它是参照审计结果重新实现的实验版本，不是 TG 源码移植，也不声称完整复现游戏画面。

## 运行与操作

在项目根目录的 PowerShell 中运行：

```powershell
./tools/run-tg.ps1
./tools/run-tg.ps1 -Capture
```

默认打开 Sponza 的 TG 模式。需要真实 GPU 和 Vulkan；不能用 headless 替代 GI 验证。

- `1` 仅直接照明；`2` TG 屏幕追踪 + BVH 回退。
- `3` 关闭屏幕追踪，始终用世界 BVH，保留时空降噪。
- `4` 仅显示间接光，使用 BVH 模式，隐藏灯的可见标记。
- `5` BVH 模式且关闭 GI 历史累积，用于观察单帧波动；空间滤波和显示端 TAA 仍开启。
- `6` 依次切换采样预算：默认 `SPARSE 4x4 / 1 RAY` → `ADAPTIVE 4x4 / MAX +50%` → `QUALITY 2/4/8 RAYS`。自适应档保留稀疏网格，仅给局部高需求区域补样；质量档是较昂贵的对照。也可用 `run-tg.ps1 -Sampling Adaptive` 或 `-Sampling Quality` 启动。
- `7` 切换默认四轮后期降噪（`POST DENOISE`）和旧单轮滤波（`BASIC FILTER`），不改变射线数或重置 GI 历史。命令行 `-BasicFilter` / `--tg-basic-filter` 可指定旧滤波。
- 大气预设中，`8` 开关天空光，联动可见天空与雾的天空源项；`-Atmosphere -NoSky` 可关闭。普通无雾预设保持原灯光配置。
- `9` 切换实验性的世界空间间接光缓存，默认关闭；`run-tg.ps1 -WorldCache` / `--tg-world-cache` 启用。`5` 无历史模式始终跳过世界缓存。
- `B` 循环放入遮挡板、移动遮挡板、移除遮挡板。GI 直接查询当前盒体位置，不重建静态传输。
- 方向键移动灯，`PgUp/PgDn` 升降，`L` 开关点光源。
- 按住鼠标右键自由转向，`WASD` 沿视线飞行，`E/Space` 上升、`Q` 下降（世界竖直方向），`Shift` 2.5 倍速度，滚轮调移动速度；相机不做碰撞。
- `P` 恢复并切换原视角 / 全景预设，`R` 复位当前相机预设及灯光。松开右键或失去焦点释放鼠标；捕获鼠标时 `Esc` 先释放，再按退出。

蓝色球是点光源的可见标记。当前 Sponza 演示测试太阳与点光源的漫反射反弹，并没有把球形网格当作面积发光源；原有真实球形发光实验仍使用 `run-ball.ps1`。

右上角显示各阶段的实际 GPU 耗时（毫秒），取最近 16 个有效计时帧的均值，每秒刷新 4 次：深度/几何引导、自适应射线分配、射线追踪、候选 SH 归约、邻域重建/历史累积、细/中/粗/大范围四个降噪阶段、历史颜色/深度复制。屏幕追踪和 BVH 在同一 dispatch 中，显示其合计；重建与历史累积也同属一个 dispatch。稀疏与自适应档跳过独立 SH 归约，只有自适应档执行预算分配，基础滤波档跳过后三轮（其单轮耗时显示在细尺度一行），关闭 GI 时各阶段显示 `--`、合计显示零。窗口缩放后面板保持在右上角。

计时来自 RenderingDevice GPU 时间戳，异步读取已完成帧，不用 CPU 提交时间代替 GPU 耗时，也不为 HUD 强制等待 GPU。各 pass 使用独立 compute list，保留渲染图的资源依赖屏障。`GI 计算合计` 包括 PRE_OPAQUE 计算区间与 POST_OPAQUE 历史复制，不包含中间的材质绘制；材质中的最终 GI 上采样包括在 `视口 GPU` 中，后者也包含直接照明等其它渲染工作。两个指标不能相加。

运行 `& (./tools/resolve-godot.ps1) --path . --rendering-driver vulkan --max-fps 60 --script tools/validate-tg-timing.gd -- --tg` 可验证阶段计时、档位切换、关闭 GI 和 960×600 缩放，结果与截图位于 `artifacts/tg-timing/`。噪点与相机误差对照抓图自动隐藏此面板，避免变化的数字污染图像指标。

## 是否仍在烘焙

**此入口不预计算照明或光照传输。** 直接绘制原始 Sponza 网格，不读取旧路径的 UV2 网格、surfel atlas、padding 或逐射线命中表，也不创建原生 VoxelGI 烘焙参考。

仍复用 `generated/sponza/` 中预先构建的三角形 BVH、三角形 UV/材质编号和缩小后的材质贴图。这些是静态几何加速数据，不含灯光、间接照度或预计算可见性结果。共享三角形文件里保留了旧 UV2 字段，但 TG shader 不使用它。光源、屏幕命中及 BVH 阴影查询每帧计算。

输入场景改变后，仍需重新准备静态三角形数据；目前不是支持任意动画网格的通用 GI 插件。独立动态盒体用解析 AABB 交点演示实时遮挡。

## 实现链路

1. **PRE_OPAQUE**：从当前帧深度重建半分辨率世界位置和几何法线，并生成局部深度遮蔽引导值。单侧深度导数选择较近的样本，减少轮廓处跨面的影响；normal/roughness 缓冲用于方向校验和退化回退。最终着色仍用法线贴图，但砖墙的凹凸贴图不再拆散几何历史。读取 Godot 已做 Vulkan 深度修正、带 TAA 抖动的相机矩阵。
2. 默认每个 4×4 最终像素区域一条均匀半球射线，移动和历史不足时也维持此预算。可选高采样档每 2×2 像素一处，静止 / 移动 / 历史不足时分别发 2 / 4 / 8 条。半球分成等立体角的分层单元，使用 Hilbert/R2 序列抖动。屏幕命中取通过深度检查的历史 HDR 颜色；失败则遍历软件三角形 BVH，执行 alpha 裁切并计算太阳/点光源照明与阴影，动态盒体也参与查询。启用天空时，向上且全场景 BVH 未命中的射线读取天空辐射，其余未命中仍为黑色；候选峰值限制为 10。
3. 各条射线在独立 GPU invocation 中并行追踪，存入候选纹理数组。先将每条 radiance/direction 对投影为 RGB 各 4 个 SH 系数，再求平均；不能把平均颜色乘平均方向代替这一过程。接收点共享 3×3 邻域 SH，按几何法线、平面距离、深度和遮蔽信号加权；空间覆盖范围与旧预算相同。候选归约独立执行一次，避免每个邻居重复处理整束光线；各 compute pass 使用 specialization constant 生成独立 pipeline。
4. 依据上一帧矩阵重投影；分别验证四个历史 tap 的平面距离、世界距离和几何法线，对有效 tap 做双线性重建，通过时累积最多 48 帧。坐标对齐深度实际采样的 full pixel `2*x+1`。保存未做空间滤波的 SH，避免每帧反复扩散模糊。
5. 默认对半分辨率 SH 做四轮 5×5 à-trous 滤波，步长 1 / 2 / 4 / 8，组合亮度方差、几何法线、双向平面距离和深度遮蔽引导。每帧重建时保存亮度一、二阶矩，沿已验证的历史 tap 累积；年轻历史以几何兼容邻域的空间方差补充估计。各轮传播方差并保留相关样本的保守下限。滤波结果不写回 SH 历史，避免反复扩散；不延长原有 48 帧历史或移动灯附近的 8 帧上限。基础滤波档保留原 3×3 单轮实现。最终材质仍按像素位置和实际法线做 4×4 引导上采样、SH 漫反射求值，经 `IRRADIANCE` 接入 Godot PBR；最终 RGB、纹理及法线贴图没有整体模糊。
6. 普通无雾预设的屏幕命中优先读取上一帧 **TAA 重建后的 HDR**。已依据本地 Godot 4.6 源码核验 `RenderSceneBuffersRD` 的 `taa/history` 纹理在 PRE_OPAQUE 阶段仍保存上一帧结果，不含色调映射。**POST_OPAQUE** 保存深度、矩阵及备用 HDR；TAA history 尚不存在时才使用备用 HDR。具备原生雾接口的大气预设改用下文独立表面历史。内部纹理命名针对已验证的 Godot 4.6 Forward+，不是跨版本稳定 API 保证。

开关灯、光色变化、灯光大幅跳变、遮挡板或 GI 模式变化会使历史失效，并暂缓 3 帧屏幕历史复用。连续小幅移灯则保留几何历史，灯附近暂将累积上限缩短为 8 帧、远处保持 48 帧，同时暂缓屏幕颜色反馈。这样避免每移动一帧就清空整屏，又限制旧照明的滞留。光源关闭仍采用硬重置，验证要求归零。窗口尺寸改变会重建内部纹理，并保持材质引用的 RenderingServer 纹理身份不变。

主要文件：

- `modules/tg_gi/TGScreenGI.{h,cpp}`：RDG 版的渲染回调、输入、历史与计时（原 `tg_screen_gi.gd`），每个阶段一个 global shader，历史用 `QueueTextureExtraction` / `RegisterExternalTexture` 跨帧；`TGScreenGI.history_effect` 为不透明阶段之后的历史捕获（原 `tg_history.gd`）。
- `shaders/tg/TGScreenGI.glsl`：几何引导、实时追踪、SH 投影、重投影及滤波（原 `tg_screen_gi.glsl`，每个阶段一个入口，只声明自己读写的资源）。
- `shaders/mesh_surface.gdshader`：最终按像素重建；保留旧网格 GI 分支。
- `scripts/sponza_lab.gd`：`--tg` 入口、交互和实际 GPU 回归。

## 稀疏预算下的前次验证

以下数字记录提高采样预算之前的降噪版本，使用本机 RTX 5070 / Vulkan、1280×800。高采样实验和当前默认稀疏后期降噪的验证分别见后文。

- 屏幕命中与 BVH 回退均实际执行，更新后的采样帧分别有 6,516 次屏幕命中、57,484 次 BVH 回退，并确认绑定了 TAA history；不是仅以功能开关推断有效。
- 历史最高累积到 48 帧，SH 全部有限。BVH 对照下，采样 SH 的帧间平均绝对变化从关闭历史时约 0.0352 降至约 0.00384。这是波动指标，不是相对路径追踪真值的误差。
- 大幅移灯触发历史失效；动态遮挡板被 949 条候选射线命中，移动过程中不建立光照传输表。
- 关闭太阳及点光源，经过 3 个稳定帧后 SH 精确归零；保持关闭后截图也没有残余光。恢复光源后重新产生有限的非零间接光。
- 相机移动后重投影仍工作；窗口缩至 960×600 再恢复后，缓冲尺寸、SH 有限性以及实际画面中的 GI 贡献均通过检查。
- 新路径的 PRE_OPAQUE GI compute 中位数约 **1.6 ms**；viewport GPU 中位数约 **3.1 ms**。前者不包含材质上采样和历史复制；后者是引擎 viewport 计时，均不能外推到其它硬件、分辨率或场景。
- 旧 Sponza 表面缓存回归通过，包括相机独立性、移灯复用静态传输、关灯归零、恢复确定性；新路径与旧路径的 GPU 日志无脚本/引擎错误。

`artifacts/tg/results.json` 保存功能与数值检查，`run.log` 保存引擎输出，`tg_gi.png` 是缩放恢复后的实际结果。另有直接照明、BVH、关闭历史、移灯、遮挡板、相机移动、关灯、仅间接光截图，以及 SH/引导调试 EXR。运行脚本同时检查功能结果、进程退出码和引擎错误。

## 噪点修正与同场景对照

用户指出初版噪点明显后，检查发现四个具体差距：独立随机采样容易聚集；最近点历史查询遇到 TAA 抖动不够稳定；使用凹凸贴图法线作为严格的几何拒绝条件会频繁丢弃同一墙面的历史；连续移灯每帧清空整个 GI。初版屏幕颜色还来自 TAA 之前，缺少 TG 所使用的稳定颜色历史。

以上已按前述链路修正。`./tools/validate-tg-noise.ps1` 固定 `--tg-sampling=0`，在相同场景、视角、灯光和射线数量下分别运行初版与改进版，记录静止序列、连续 60 次小幅移灯、停下后的序列以及关灯检查。`--tg-legacy-denoise` 仅用于重现初版对照，默认启用改进版。这组对照仅隔离降噪改动，不包括后续的采样预算提升。

2026-09-28 的最终结果位于 `artifacts/tg-noise/comparison.json`：

- 静止时采样 SH 的帧间变化约为初版的 **29.9%**，下降约 70%；最终画面采样 RGB 的帧间变化约为 **60.0%**，下降约 40%。
- 连续移灯时 SH 变化约为初版的 **24.1%**，下降约 76%；此数值同时含实际照明变化，不能等同纯噪声方差。
- 静止时有效表面的平均历史年龄从约 **27.2 帧** 提升到 **46.5 帧**。连续移灯时，硬重置次数从 **60 次** 变为 **0 次**，灯附近平均保留约 **7.8 帧**；关灯仍硬重置且结果精确归零。
- 停下后采样 SH 波动约为初版的 **28.4%**。未增加每帧 GI 候选射线数量，墙角/遮挡、相机、缩放和旧网格 GI 回归另由完整测试覆盖。

上述 SH 指标是打包纹理的采样通道平均绝对差，不是相对高采样参考的图像误差，也不能证明完全无噪点。前后实际截图分别位于 `artifacts/tg-noise/before/` 和 `after/`，`moving.png` 可观察移动过程中的墙面斑块。法线贴图仍用于最终 PBR 和 SH 求值；并未通过模糊整张最终画面、降低纹理细节来获得这些结果。

## 连续移动相机与初始采样预算

以下记录四轮后期降噪之前的高采样实验，目前保留为可选对照档。此前静止和移灯的帧间差测试没有充分验证连续移动相机。实验将预算提高为每 2×2 像素一处、静止 / 移动相机 / 历史不足分别 2 / 4 / 8 条射线，相对 4×4 单射线是 8 / 16 / 32 倍密度。相机检测忽略 TAA 的投影抖动，实际位姿或投影缩放改变后短暂保持移动预算。该实验没有延长 48 帧历史或扩大空间滤波范围；`validate-tg-camera.ps1` 固定基础滤波以继续隔离采样差异。

运行 `./tools/validate-tg-camera.ps1 -Python <python.exe>`（需要 numpy）可重现。三组采用完全相同的场景、材料、光源、降噪参数和相机轨迹：旧稀疏预算、新自适应质量预算、每个半分辨率接收点固定 32 条射线的高采样参考。先测无历史的冷启动，再平移 48 步并在 6 个位置保存样本，最后静止收敛。误差测试关闭屏幕颜色反馈、仅用 BVH，以隔离采样预算；另有屏幕 + BVH 集成移动测试、运行时预算切换与关灯归零。

2026-09-28 最终结果保存在 `artifacts/tg-camera/comparison.json`：

- 冷启动间接光 MAE 约为旧预算的 **23.0%**，下降约 **77%**。
- 连续相机平移的平均间接光 MAE 约为旧预算的 **24.7%**，下降约 **75%**；历史年龄不足 8 帧的区域，误差约为旧预算的 **21.5%–27.5%**。
- 按世界位置与法线匹配像素，测试各姿态的有效几何匹配率为 100%。SH 在相同接收法线上求漫反射入射量，再与高采样结果比较；这不是直接比较移动前后的画面，也不是通过模糊最终纹理降低帧差。
- 1280×800 下，旧预算每帧 64,000 条候选射线；新预算冷启动 2,048,000 条、稳定视角约 545,000 条，测试中的移动帧约 1,210,000–1,420,000 条。历史年龄在两种预算下保持相同。

- 当时质量预算的完整 `run-tg.ps1 -Capture` 回归通过：屏幕/BVH、历史降噪、移灯、动态遮挡板、相机、窗口缩放和关灯归零均正常，GPU 日志无脚本/引擎错误。屏幕 + BVH 模式的静止 GI compute 中位数约 **13.25 ms**，viewport GPU 约 **14.67 ms**。后续计时 HUD 回归记录在 `artifacts/tg-timing/regression.log`，分别约 13.23 / 14.76 ms；`artifacts/tg/results.json` 现已更新为下文的默认稀疏后期降噪结果。

参考仍是同一个近似渲染器，不是无偏路径追踪真值；上述百分比是本轨迹下的间接光误差下降，不能外推成任意视角最终画面的“噪点消除率”。实际相机运动截图在 `artifacts/tg-camera/sparse/` 与 `quality/`，例如 `pan_24.png` 和 `tg_camera_motion.png`。

## 2026-10-08：局部自适应稀疏采样

新增 profile 3（`-Sampling Adaptive` / `--tg-sampling=3`），原稀疏 profile 0 仍为默认。每 4×4 全分辨率像素保留一条基础射线；在每个 8×8 追踪工作组内，最多为一半有效接收点各增加一条射线。上限依据有效几何数量计算，天空与不完整边缘块不产生虚假预算。这里的 50% 上限指 GI 候选射线，不是含阴影查询的总遍历次数或 GPU 耗时上限。

预算 pass 先按世界位置、双向平面距离和法线验证上一帧的四个重投影 tap，再读取历史年龄与亮度矩。优先级依次为年龄不足 8 帧、移动点光源附近、相对标准误差超过 0.15；分母有 0.025 的亮度下限，避免极暗区域消耗全部预算。满足同一优先级的接收点用逐帧变化的排列打破平局。决策只依赖历史与当前几何/灯光状态，不读取本帧候选辐射。候选按实际射线数归一化；历史长度、邻域重建范围和四轮滤波参数保持不变，交互期间没有 GPU 数据回读。

相对旧稀疏路径，1280×800 下增加约 1.1 MB 纹理（第二层候选颜色/方向与 8 位预算图）。预算图还记录触发原因供测试读取；新计数器 8–11 分别记录有效接收点、因年轻历史/方差/移动灯得到补样的接收点，计数器 7 在自适应档记录补样总数。既有质量档的计数器 7 仍表示使用 8 射线的新历史接收点。

`./tools/validate-tg-adaptive.ps1 -Python <python.exe>` 串行运行稀疏、固定额外 50% 射线、自适应和 32 射线参考，全部使用相同后期滤波。参考每次重新生成；误差捕获使用 BVH-only，另外检查屏幕反馈集成。结果位于 `artifacts/tg-adaptive/comparison.json`，2026-10-08 本机结果：

- 冷启动间接光 MAE 下降 **13.1%**；移动轨迹平均下降 **11.5%**，其中年轻历史区域下降 **15.3%**、几何边缘区域下降 **11.4%**。静止两个样本的平均误差下降 **6.3%**。
- 稀疏档每帧 64,000 条候选；自适应冷启动 96,000，移动样本 71,908–78,720，静止样本 64,664–65,318。每个捕获工作组的预算均符合上限；所有模式的采样帧号与历史年龄逐值一致，几何匹配率 100%。
- 固定补样对照始终发射 96,000 条射线。自适应的移动 MAE 是其 **1.005 倍**，但移动射线数少约 **18%–25%**；静止误差稍高于固定补样，换取空闲区域预算回落。该对照通过测试专用的 `--tg-uniform-budget` 关闭优先级，交互档不使用此参数。
- 本轮静止 GI compute 中位数约 1.235 ms（稀疏）、1.276 ms（自适应）、1.614 ms（固定补样）；自适应运行时预算 pass 约 0.024 ms。本轮 Godot 编辑器与用户演示仍在运行，这些耗时只作诊断，不是隔离环境的性能保证。
- GPU 运行时检查通过移动灯触发局部补样、无历史预算、997×613 非整倍数尺寸、部分天空/纯天空及 `6` 键三档往返。完整回归通过屏幕/BVH、动态遮挡、重投影、缩放、降噪、关灯精确归零和开雾共存。报告分别在 `runtime/`、`regression/`、`fog/`，日志无脚本/引擎错误。

误差来自相同近似渲染器的高采样参考，不是无偏路径追踪真值。此轮实现和收益适用于 Sponza 的 TG GI；城市仍使用原生照明，远景雾继续沿用已修复的完整覆盖方案。

## 2026-10-09：开雾时的独立表面历史

本地引擎新增只读原生雾纹理接口后，大气预设按“无雾材质着色 → POST_OPAQUE 表面历史 → 原生积分雾合成 → 天空/透明 → 显示 TAA”执行。GI 屏幕查询只读独立表面历史，开雾时可继续进行屏幕反馈；不支持接口的引擎仍自动回退 BVH。普通无雾预设沿用既有 TAA 颜色路径。实现、构建方式、约 12.3 MB 额外缓存及边界详见 [大气与 GI 共存](TG_ATMOSPHERE.md#与-tg-gi-共存)。

## 2026-10-09：共享天空光源

Sponza 大气预设默认把 `TGAtmosphere.sky_color` / `sky_energy` 用作 GI、可见天空和雾的基础光源。颜色只做一次 sRGB → 线性转换；GI 与天空 shader 使用相同线性辐射，雾 shader 的 `source_color` 由 Godot 转换。`8` 开关、`--tg-no-sky` / `run-tg.ps1 -Atmosphere -NoSky` 可对照。天空是独立光源，关闭太阳/点灯后仍会照亮可见天空的表面；全部光源归零测试现在也显式关闭天空。

当前使用恒定上半球、黑色下半球。射线必须穿过场景才取得天空光，不使用全局环境填充；原有 alpha-cutout 与动态盒体遮挡继续参与查询。天空方向的 BVH 查询不在原来的 80 米处截断，防止远处遮挡被误认成天空，仍是一条候选、一次 BVH 查询。没有增加 GI 采样预算或图像缓冲，只增加一组源参数和计数器 12（天空命中数量）。较远遍历与天空绘制可能增加开销，本轮未作性能收益结论。

天空颜色、强度或开关变化触发原有硬历史失效及三帧屏幕冷却。雾开关、浓度和太阳介质衰减不改变天空入射源，因此保持表面历史与雾的隔离。雾保留既有的径向权重、雾色和衰减公式；这是共享基础颜色与强度，不是完整的大气天空辐射求解，也不是 TG 原天空模型的复现。

`./tools/validate-tg-sky.ps1 -Python <python.exe>` 在真实 Vulkan 下检查 11 个状态及实际 `8` 键输入，结果在 `artifacts/tg-sky/`。固定无 TAA 抖动、无屏幕反馈的天空单光源测试中，62,579 条候选有 2,254 条取得天空辐射，其余为零；所有非零候选方向向上、数值与输入源一致，强度减半精确对应一半候选值。150 米高的遮挡屋顶阻断全部天空候选与 SH；移除后候选逐值恢复，关闭天空后三帧内 SH 归零。另覆盖色温变更、屏幕反馈、自适应预算和 997×613 缩放。

默认世界 BVH 命中点的着色只计算太阳/点灯，未额外采样命中点的天空可见性，因此默认 BVH-only 不含天空在第二个表面上的反弹。后续可选世界缓存能补入已观察表面的间接照明，见下一节。屏幕路径也可通过既有表面历史传播天空照明；这些仍是有偏反馈，不是无偏多次反弹求解。城市没有接入这条 Sponza GI，远城雾覆盖方案不受影响。

加入天空后的回归仍通过七组原生/分离雾合成对照（MAE 0.000021–0.000047），十组开雾/关雾的 SH、表面辐射、几何与历史年龄仍逐值一致；所有灯光连同天空关闭时，两边最终显示也精确为黑色。完整自适应 GI 回归通过屏幕/BVH、动态遮挡、移动灯、降噪、三帧归零和缩放，报告在 `artifacts/tg-sky/regression/`。城市/Sponza/拱廊多次往返也通过，日志在 `artifacts/tg-sky/viewer.log`。本轮另有用户编辑器同时运行，计时只留作诊断，不作为加速或变慢的比较结论。

## 2026-10-09：实验性世界空间间接光缓存

新增可选 `-WorldCache` / `--tg-world-cache`，`9` 键切换，默认关闭。相机转开之后，BVH 命中仍可取得最近观察到的表面间接照明，减少只剩太阳/点灯着色的缺失。缓存尚未观察到的区域继续使用原有 BVH 回退；这不是完整的、与相机无关的世界光照解。

缓存保存几何法线方向的漫反射间接照度 / π，来源是本帧已降噪 SH，不直接缓存接收面的最终 RGB、反射率或镜面高光，雾不会写入。原有屏幕追踪仍以历史表面 RGB 近似来光，其视角偏差不会因此消失。命中静态三角形后，在原有直接照明上补入缓存照度，最后乘命中材质的漫反射率。动态盒体命中不查询缓存，写入也排除盒体及其周围 2.5 厘米范围，避免把可移动表面留在原地。

实现采用固定 65,536 桶的 GPU 哈希表，每条 64 字节，另有 4 字节写入者索引，合计 **4.25 MiB（约 4.46 MB）**。首次启用才分配完整缓冲；关闭后保留分配供再次启用，退出场景释放。0.25 米空间格与主法线方向组成完整键；哈希冲突只能造成漏查，不能仅凭桶号接受记录。查询还检查法线点积 ≥ 0.95、双向平面距离 ≤ 1 厘米和位置距离 ≤ 0.4 米。不跨桶插值，因此覆盖率与空间连续性仍有限。

两个更新 pass 位于 GI 滤波之后：`cache_select` 用整数 atomicMin 按到世界格中心的量化距离选择成熟接收点，同分时以像素索引决定；`cache_resolve` 每桶只允许一个写入者。查询与更新位于不同 pass，无原地并发读写竞争；缓存不随视口尺寸重建。只接纳历史年龄至少 8 帧的表面，照度限幅 10，与候选限幅一起约束异常值。缓存会在失去刷新后的第 90–120 个有效 GI 渲染帧逐渐淡出，120 帧后无效；这不是固定的墙钟秒数。交互运行不回读缓存，只有测试通过调试接口导出 GPU 数据。

太阳/点灯、天空或遮挡输入改变时立即推进有效版本，使旧记录无法命中。普通硬变更同时沿用 GI 历史重置；连续小幅移灯保留原有局部 GI 累积，但世界缓存等待停止变化后 48 帧再写入，避免把移动灯的历史滞后带到屏幕外。GI 开关、追踪模式和无历史模式切换也使旧记录失效；`5` 模式不查询或更新缓存。光源稳定时，相机运动与分辨率变化不清空世界记录。

缓存增加两个更新 pass 和命中查询，不额外发射 GI 候选或天空射线。它补足的是已有照明的短期离屏复用，本轮不声称净加速、完整多次反弹或无偏精度提升。0.25 米覆盖、1 厘米平面容差、几何法线近似、SH 滤波和反馈仍可能产生误差；不能据受控测试保证任意细薄几何都不漏光。城市尚未接入这条缓存。

## 与 TG 的差异及当前边界

当前遵循 TG 的总体结构，局部实现仍有明确差异：使用 Godot 的 TAA 而非 TG 自己的 TAA；候选共享使用 9 点而非 TG 的 8 点布局；遮蔽引导是局部深度近似，不是 TG 的地平线积分；最终上采样布局也不同。几何法线降噪、四 tap 的逐点历史验证和移动灯附近的短历史是本项目针对 Sponza 的实现选择，不应归为 TG 已证实的具体实现。没有实现或声称实现完整 ReSTIR GI。

可选的 2/4/8 射线预算也是面向本实验的质量选择，不能据此宣称 TG 使用同样的射线数。默认四轮方差引导后期滤波借鉴 [SVGF 的时空方差与多尺度重建思路](https://research.nvidia.com/publication/2017-07_spatiotemporal-variance-guided-filtering-real-time-reconstruction-path-traced)，是本项目在 SH 数据上的简化实现，不是完整 SVGF 移植，也不是已证实的 TG 配置。TG 的审计配置缺少运行时分辨率、调度和全部变体的证明，单帧噪声水平也取决于场景照明的采样方差；只套用一个稀疏配置不足以保证相同观感。

默认世界回退计算一次漫反射反弹。屏幕颜色包含前帧 GI、或启用上述世界缓存时会形成跨帧反馈，无法称作固定、无偏的多次反弹求解；候选限幅、低阶 SH 和空间滤波都会引入偏差。世界缓存只短期保留已观察的表面，移动相机仍可能改变结果，和旧世界空间缓存的相机独立性不同。

当前没有 TG 的地形高度图、原天空模型与艺术补光、任意网格的实时 BVH 更新或任意离屏自发光材质查询；上述简化天空仅为本项目的共享光源。Sponza GI 材质使用 512×512 贴图，alpha 边缘和最终高分辨率材质存在差异。低采样率、屏幕缺失和历史重置仍可能造成细薄结构漏光、运动噪点、方向细节损失；本轮通过项不等于全场景画质保证。
