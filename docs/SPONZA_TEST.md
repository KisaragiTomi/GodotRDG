# Sponza 网格 GI 测试

本文描述原有的世界空间表面缓存方案。新增的 TG 风格每帧追踪方案使用 `./tools/run-tg.ps1`，详见 [TG 实现说明](TG_SCREEN_GI.md)；两套启动入口保留，便于对照。

2026-09-28：经典 Crytek Sponza 已接入独立的网格表面缓存路径，可以在同一视角、相同材质和灯光下切换直接照明、自研 GI、原生 VoxelGI 和仅间接光。原有盒体实验路径保持独立。

在仓库根目录运行 `./tools/run-sponza.ps1`。启动时会先生成原生参考，再建立自研静态传输，通常需要数秒。

- `1` 关闭 GI，`2` 自研网格表面缓存 GI，`3` Godot VoxelGI 256，`4` 仅自研漫反射间接光。
- 按住鼠标右键自由转向，`WASD` 沿视线飞行，`E/Space` 上升、`Q` 下降，`Shift` 加速，滚轮调移动速度；相机不做碰撞。`P` 恢复并切换原视角 / 全景预设，`R` 复位当前相机预设和灯光。
- 方向键沿画面方向移动灯，`PgUp/PgDn` 升降，`L` 开关灯。松开右键或失焦释放鼠标；捕获鼠标时 `Esc` 先释放，再按退出。灯的位置限制在中庭范围，尚未做三角网格碰撞。
- 蓝色球是 OmniLight 的可视化标记；此场景测试方向光和动态点光源的反弹，不是球体面积自发光测试。之前的真实球形发光源测试仍使用 `run-ball.ps1`。

## 实现

离线准备只生成几何数据，不烘焙照明：Godot 展开 UV2，按 0.3 米目标间距生成 666×662 atlas，实际有效表面采样点 116,008 个。保留 262,267 个三角形，构建 65,781 个节点的无栈 BVH；射线查询包含材质透明裁切。漫反射输运按贴图采样反射率，并抑制金属材质的漫反射项。

GPU 初始化为每个表面采样点记录 256 条确定性余弦分布射线的命中位置。灯光改变时执行 BVH 阴影查询、直接出射光计算和两轮有限漫反射传播，复用静态传输。显示材质从 UV2 atlas 读取 E/π，通过 Godot 的 IRRADIANCE 接入原生 PBR。贴图法线保留在最终材质中，传输使用网格顶点法线。

相机不参与 GI 采样或更新。没有 GI 跨帧历史；显示端为材质与几何抗锯齿启用了 TAA。环境补光、SSAO、SSIL、辉光均关闭。自研模式关闭 VoxelGI，原生模式关闭自研间接光，避免叠加两套结果。

运行 `./tools/prepare-sponza.ps1 -Python <python.exe>` 可以重新生成几何缓存；Python 依赖 numpy、scipy、Pillow。文件在 `generated/sponza/`，上游原始资源不修改。`mesh_cache.gd`/预处理工具目前针对这一份静态 Sponza 布局，不是通用资产导入插件；几何发生变化时应重新准备并重建传输。

## 验证

运行 `./tools/run-sponza.ps1 -Capture` 自动生成 `artifacts/sponza/results.json`、四种照明模式截图、移灯截图与线性 HDR atlas。

检查包含：GI 开关画面差异、有效 atlas 有限非负、相机移动时 atlas 逐字节不变且没有照明更新、移灯改变 GI 且静态传输只建立一次、关闭全部灯后 RGB 精确归零、恢复灯光后 atlas 逐字节一致。原生 VoxelGI 用作外观参考，不是路径追踪真值或误差通过阈值。

本机 Godot 4.6.1 / Vulkan / RTX 5070 初次测试：静态 GPU 传输约 3.05 秒，单次 GPU 照明更新约 2.4 毫秒；静止时不提交照明 dispatch。传输记录占 118,792,192 字节（约 113.3 MiB），另有几何、atlas、材质和原生参考资源。viewport 渲染时间和上述 compute 时间分别记录，不可把静止 viewport 时间当作动态 GI 的完整帧耗时。

## 当前边界

这是一条可运行、可比较的网格实验路径。0.3 米空间采样和 256 条固定射线仍会损失小于采样尺度的遮挡与反弹细节；UV chart 边缘用有限距离 padding 重建，没有通用逐像素可见性过滤。双面薄布的输运仍按展开后的单面法线近似。GI/透明遮挡使用缩到 512×512 的贴图，最终绘制使用原分辨率贴图；细叶边缘会存在精度差异。暂不包含天空照明、任意纹理自发光输入、动态网格遮挡或镜面间接传输。性能数值与功能断言不构成全场景无漏光、无噪点或物理误差验收。
